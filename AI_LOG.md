# Использование ИИ

Первый комплект: 16.10.2026, Москва. Записи отражают разработку ассистентом. Согласование решений студентами и проверка gold ещё ожидаются.

| № | Запрос/задача | Предложение ассистента | Решение при подготовке | Проверка |
|---|---|---|---|---|
| 1 | Начать ЛР6 для прежней пары | Утечка тестовой сборки | Вымышленная «Ладога» | Состав пары найден в контексте |
| 2 | Перенести условия в данные | 10 документов и 36 claims | Два нерелевантных источника | validate_data.py |
| 3 | Проверить объём | Первый текст: 4541 слово | Дополнены пояснения источников | Пересчёт: 5194 слова |
| 4 | Ошибка логики gold | GET svc-demo легко приписать Льву | Такая связь отклонена, Q11=insufficient | C18/C19, физической атрибуции нет; проверка людьми ожидается |
| 5 | Доказуемая многошаговая связь | Чтение внутри интервала права | Q03 соединяет выдачу, GET и отзыв | C03/C04/C05 |
| 6 | Ошибка p-adic кодирования | Числовой код удобен для хранения | abs(code_x-code_y) отклонено; расстояние по префиксу | Проверка трёх уровней и всех 19683 троек путей |
| 7 | Удаление посылки | Удалить только claim недостаточно для A | Изъят и фрагмент документа | Тест полного контекста; смысловые дубли проверяют люди |
| 8 | Добавить both к insufficient | Одно сообщение не создаёт две стороны | Один документ с двумя несовместимыми сообщениями в Q11/Q12 | Существуют обе ссылки, вариант требует проверки |
| 9 | Генерация тестов | Проверить JSON, ссылки, отказ API, B/C, UI | Тесты не требуют модели | pytest |
| 10 | Исправить запуск проверок | Из родителя не находился src | Исправлен каталог запуска | pytest из корня проекта |
| 11 | Проверить retrieval | Измерить покрытие gold в top-15 | Gold не добавляется в retrieval | Для Q12 C21 не попадает; ограничение сохранено |
| 12 | Подготовить отчёт | Создавать по сохранённым ответам | Нет заглушек LLM-метрик | Генератор требует predictions.jsonl |

Пока не выполнены: генерация Qwen, совместная семантическая проверка gold, анализ реальных ответов и защита. Тестовые адаптеры существуют только в pytest и не считаются исследовательским прогоном.
